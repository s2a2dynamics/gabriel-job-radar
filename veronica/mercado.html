Lectura estratégica: el mercado europeo está creciendo y el mayor diferencial para Verónica está en la frontera entre ciencia e ingeniería: instrumentación astronómica, payloads científicos, software científico, space data, mission science y computational astrophysics. Los gaps marcados como “por verificar” no significan carencia: son competencias que aún no tenemos documentadas en su perfil.

Plan recomendado de cierre de gaps

  1. Sept–Oct 2026: auditoría real de skills: lenguajes, herramientas, notas, proyectos y laboratorio. Sustituir “gap probable” por evidencia.
  2. Oct–Dec: Python científico + Git + Linux + un proyecto astronómico reproducible.
  3. Nov–Feb: elegir TFG deliberadamente: idealmente astrofísica/cosmología con componente computacional o instrumentación científica.
  4. Ene–Mar 2027: construir segundo proyecto: CubeSat/mission analysis o instrument control; aprender ECSS/SysML.
  5. 2027: aplicar simultáneamente a prácticas Space Engineering, Summer Research y Másteres; usar los resultados para decidir entre academia, ingeniería o perfil híbrido.
